# Alaska Prep

Heli-ski conditioning tracker for the March 13, 2027 Alaska trip. A single self-contained `index.html`: no build step, no dependencies. Installed to the iPhone home screen as a web app.

All data lives in the phone's browser storage under `alaskaprep.v1.*`. Use **Data → Save backup file** regularly.

Deployed by Vercel on every push to `main` (framework preset Other, no build command, no output directory).
